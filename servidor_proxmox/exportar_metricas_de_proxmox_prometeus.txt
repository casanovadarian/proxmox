1. Crear un Usuario de Monitoreo en Proxmox VE
Crea un usuario: En la interfaz web de Proxmox, ve a Datacenter > Permissions > Users.

Crea un Token API: Para evitar usar la contraseña, crea un API Token para ese usuario. Esto se hace en Datacenter > Permissions > API Tokens.

Usuario: El usuario que acabas de crear (ej. prometheus@pve).

Token ID: Un nombre para el token (ej. exporter).

Importante: Cuando crees el token, guarda el valor del secreto (secret value), ya que solo se mostrará una vez.

Asigna Permisos: Asegúrate de que el usuario tenga el rol PVEAuditor en la ruta / (o la que necesites).

2. Instalar y Configurar el PVE Exporter
    Instalar Python y Pip:
    1: Usar un Entorno Virtual (venv)
        apt update && apt install python3-full -y

    2: Crea el entorno virtual e instala el exportador:
        # Creamos el directorio y el entorno
        mkdir -p /opt/prometheus-pve-exporter
        python3 -m venv /opt/prometheus-pve-exporter/venv

        # Instalamos el paquete dentro del entorno virtual
        /opt/prometheus-pve-exporter/venv/bin/pip install prometheus-pve-exporter

    3: Configura el servicio de Systemd:
    Cuando crees el archivo /etc/systemd/system/prometheus-pve-exporter.service
        [Unit]
        Description=Prometheus Proxmox VE Exporter
        After=network.target

        [Service]
        User=root
        # Apuntamos a la ruta del venv
        ExecStart=/opt/prometheus-pve-exporter/venv/bin/pve_exporter --config-file /etc/prometheus/pve.yml
        Restart=always

        [Install]
        WantedBy=multi-user.target

3.  Instalar el Exporter:
    pip3 install prometheus-pve-exporter

4.  Crear el Archivo de Configuración (pve.yml): Crea un archivo para que el Exporter sepa cómo autenticarse con la API de Proxmox.
    nano /etc/prometheus/pve.yml
    default:
      user: tu_usuario@pve # Ej: PVEAuditor@pve
      token_name: token_id_que_creaste # Ej: exporter
      token_value: el_valor_secreto_que_guardaste #Ej: c9a198cf-e635-4551-b9f9-72423967468a
      verify_ssl: False # Cambia a True si usas certificados válidos

5.  Activar el servicio
    systemctl daemon-reload
    systemctl enable --now prometheus-pve-exporter

6.  Comprobar el servicio
    ss -tulpn | grep 9221
