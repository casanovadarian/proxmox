#Crear uno o dos servidores para LB 
1- Install HAProxy and KeepAlived:
    sudo apt-get install haproxy keepalived

2- Add the following to /etc/haproxy/haproxy.cfg on lb-1 and lb-2:

frontend k3s-frontend
    bind *:6443
    mode tcp
    option tcplog
    default_backend k3s-backend

backend k3s-backend
    mode tcp
    option tcp-check
    balance roundrobin
    default-server inter 10s downinter 5s
    server server-1 10.12.118.101:6443 check        # direccion del master
    server server-2 10.12.118.102:6443 check        # direccion del master
    server server-3 10.12.118.103:6443 check        # direccion del master

3- Add the following to /etc/keepalived/keepalived.conf on lb-1 and lb-2:

global_defs {
  enable_script_security
  script_user root
}

vrrp_script chk_haproxy {
    script 'killall -0 haproxy' # faster than pidof
    interval 2
}

vrrp_instance haproxy-vip {
    interface eth1              # usar el de la maquina
    state <STATE> # MASTER on lb-1, BACKUP on lb-2          # usar el del lb en el que este
    priority <PRIORITY> # 200 on lb-1, 100 on lb-2          # usar el del lb en el que este

    virtual_router_id 51

    virtual_ipaddress {
        10.12.118.100/24
    }

    track_script {
        chk_haproxy
    }
}


4- Restart HAProxy and KeepAlived on lb-1 and lb-2:
    systemctl restart haproxy
    systemctl restart keepalived

#####COMPROBACIONES#####
-------------------------
1- Verificar la IP Virtual (VIP)
ip addr show ens18          # Cambiar ens18 por tu interfaz de reload

2- Verificar el Balanceo de Carga (HAProxy)
nc -zv 10.12.118.100 6443           #Poner el VIP

3. Prueba de Fuego: Alta Disponibilidad (Conmutación)
Esta es la prueba real de que tu configuración es robusta:
En una terminal, deja un ping constante a la VIP: ping 10.12.118.100.
Apaga o reinicia lb-1 (sudo reboot).
Observa el ping: Deberías perder solo 1 o 2 paquetes.
Ve a lb-2 y ejecuta ip addr show ens18. Verás que la IP .100 ahora vive allí.
Cuando lb-1 vuelva a encenderse, la IP regresará a él automáticamente porque tiene mayor prioridad (200 vs 100).
